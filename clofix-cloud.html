Security

VPS Protection Mode

Protection Mode is a per-FileVPS switch. When it is On, the guest root filesystem is mounted read-only. An attacker who lands in the VPS cannot write system files, drop malware into /etc or /usr, or persist changes on the OS layer.

StateWhat happens
On (default for new VPS) Persistent guest root is read-only. Attackers and scripts cannot write the system tree. Temporary paths (/run, /tmp, /var/log, APT cache) stay writable and clear on restart. apt update can refresh indexes. Processes and network keep running.
Off Root becomes writable so you can install packages or change system files. Turn Off only for that maintenance window, then turn On again for production. Toggling restarts a running VPS.
  • On = read layer for the OS - no write to the protected system root
  • Attached Volume / EFS / S3 paths stay writable for app data while root stays read-only
  • Does not stop processes or network traffic
  • Does not inspect HTTP payloads - use WAF for SQLi / XSS / RCE
  • Not a substitute for hardware VM isolation
  • Manage at VPS Details → Security and Security Center

CloFix Cloud FAQ

Answers about CloFix Cloud features, Protection Mode, WAF, CKS, Docker, billing, storage, and licensing.

What is CloFix Cloud?

CloFix Cloud is multi-tenant cloud console software. One login covers FileVPS, CKS, Docker, Library apps, storage, networking, Protection Mode, OWASP CRS WAF, IAM, partners, and billing.

What is FileVPS?

FileVPS are OS-level Linux guests on enrolled workers. They share the host kernel with OverlayFS and cgroup v2 limits. Create is typically tens of milliseconds; guests are ready in about two seconds. FileVPS is not a KVM/QEMU hardware VM.

How dense are FileVPS guests on a worker?

Guests share the host kernel, so idle cost stays low. Create median is about 38 ms and ready about 1.7 s. Idle host RAM per VPS is about 1.6 MB. A networked pack can run 100 SSH-ready VPS on one worker. Placement uses live free CPU, RAM, and disk with no RAM overcommit.

Can I deploy an app without a VPS?

Yes. Library Quick Apps deploy managed sandboxes with no FileVPS and no SSH box (HTML, PHP, Node, Next.js, WordPress, Adminer, Jenkins). Jobs & Functions also run code without creating a VPS. For containers, use Docker Quick App templates on the worker Docker Engine. For a full guest, install VPS software into a running FileVPS.

What are Jobs & Functions?

Jobs & Functions run Python, Go, Node, PHP, Java, Ruby, Bun, or Deno without creating a FileVPS. Each run gets a fresh overlay, unprivileged UID, limits, and a private network - useful for scripts, automation, and scheduled work. Workers advertise which runtimes they support.

Do tenants get Docker socket access?

No. Containers run on the worker-host Docker Engine (admin opt-in). Tenants never receive docker.sock. Use Docker Quick App templates, image wizard, Compose, and Git build without giving tenants host Docker control.

What does Protection Mode do?

When On (default for new VPS), the guest root filesystem is read-only. Attackers cannot write system files under the protected root. Temporary paths such as /run, /tmp, and /var/log stay writable and clear on restart. Attached Volume / EFS / S3 paths stay writable for app data. Turn Off only to install packages, then turn On again. Toggling restarts a running VPS.

How is WAF different from Protection Mode?

Protection Mode locks the guest filesystem. WAF is a worker-shared OWASP CRS edge engine for HTTP/HTTPS payloads such as SQLi and XSS. Bind FileVPS or Docker targets in /waf. WAF does not cover SSH or raw TCP.

What other security controls are included?

Besides Protection Mode and WAF: SSH Login Block, SSH Key-Only, Delete Protection, Security Modes (Standard / Hardened / Lockdown / Maintenance / Web Block), Network Quarantine for incidents, and Security Center with score, findings, audit trail, and fleet apply.

Does CloFix Cloud include Kubernetes?

Yes. CKS (CloFix Kubernetes Service) provides EKS-style clusters, node pools, workloads, Helm, and kubeconfig on dedicated CKS workers. FileVPS guests cannot run kubelet. The Kubernetes API stays on the worker - port 6443 is not published publicly.

What storage and databases are included?

Volumes (1:1 durable disk), EFS (shared web root), S3 object storage and mounts, VPS writable-layer backups, plus managed MySQL, PostgreSQL, MongoDB, and Redis projects.

When should I use Volumes, EFS, or S3?

Volume - durable disk attached 1:1 to one VPS on the same worker. EFS - shared web root across VPS or load balancers. S3 - object storage and s3fs mounts. VPS backup - clone or recover the writable layer onto a new FileVPS on the same worker.

What networking features are included?

VPC on 10.231.0.0/16, controller DNS zone with auto records and BIND export, ALB and NLB load balancers, health checks (HTTP / TCP / ICMP), and firewall rules for FileVPS, apps, and database TLS ports.

How do I access a FileVPS over SSH?

FileVPS supports SSH key, PAM password, or both. PEM download is available once at create. Guests use a private bridge on 10.231.0.0/16 with published SSH, HTTP, and HTTPS ports.

How do workers connect to CloFix Cloud?

Partners and root clients operate on enrolled Linux workers over mTLS. The console places work from live free CPU, RAM, and disk capacity on those workers - no RAM overcommit.

How does billing work?

Due bill meters by the minute. Stopped VPS or database instances bill storage only. Resource Pricing supports Standard and Low-cost monthly and hourly rates. The platform also covers invoices, wallets, subscriptions, credits, and license quotas for VPS, CKS, Docker, load balancers, DNS, and backups.

Who is CloFix Cloud for?

Companies that run their own multi-tenant console on Linux workers; MSPs and partners who resell seats; root clients with full account control; and IAM users with scoped permissions for instances, Kubernetes, databases, and more.

Can partners resell CloFix Cloud?

Yes. Partners manage client accounts and billing. Root clients control their full account. IAM users receive scoped permissions for instances, Kubernetes, databases, and more.

How do I buy or license CloFix Cloud?

Contact CloFix sales to license the controller and workers for your company, MSP, or partner channel. Become a partner if you want to resell seats.
