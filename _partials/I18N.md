# CloFix site i18n

English (`en`) is the default. Preference is saved in `localStorage` (`clofix-lang`).

## How it works on every page
1. **Header + footer** — precise strings via `data-i18n` + `js/i18n.js` (marked `notranslate`).
2. **Page body** — the language menu updates the Google Translate cookie (`googtrans`) and applies the selection to the translator as soon as it is ready. Switching between translated languages updates the current page; returning to English reloads once to restore the source text.
3. Script paths are relative to each page (`js/i18n.js`, `../js/i18n.js`, etc.) so both hosted pages and pages opened directly with `file://` can load the language controls.

## SEO rules (keep)
- Source HTML stays `lang="en"` with English copy, canonical, and `hreflang="en"` + `x-default` only.
- Do **not** add fake locale URLs / hreflang for Translate-only languages.
- Search crawlers skip Google Translate injection so they index English HTML.
